# VM Evidence Checklist

Add evidence created by you in your own ROS 2 VM. Suggested files:

- `turtlesim-executables.txt` - output of `ros2 pkg executables turtlesim`
- `turtlesim-running.png` - turtlesim window after keyboard movement
- `rqt-service-caller.png` - RQT with **Plugins > Services > Service Caller** open
- `rqt-console.png` - RQT Console showing a log message/filter
- `workspace-build.txt` - your `colcon build` output or final success lines
- `workspace-tree.txt` - a directory listing showing `src`, `build`, `install`, and `log`
- `package-run.txt` - actual output from `ros2 run week4_activity my_node`
- `myturtlesim.png` - optional: the modified title bar after completing the overlay exercise

Do not add fabricated output. If a command fails, keep the real output and briefly record what you fixed.
